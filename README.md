# NHMEC Herbalist Learning App — Version 16

Version 16 builds on the working Version 15 app and adds only course material supplied in the conversation. Unfinished courses remain placeholders; no missing lessons, numbers, forms, or assignments are invented.

## Added / updated in Version 16

- **NHMEC 205 — Herbs for the Overwhelmed Woman: Supporting the Nervous System Naturally** now opens as a real course resource area with the supplied clinical revision guide, printable worksheet, and presentation. The large presentation was split into **6 GitHub-friendly MP4 parts**. The 37-page guide was split into **2 PDF parts**. The class is still marked under construction because the final lesson sequence is not yet complete.
- **NHMEC 302 — Veterinary Clinical Anatomy & Disease Recognition** now includes the supplied **9-module** structure, reading assignments, final-project options, certificate requirements, textbook/workbook Drive links, the supplied Veterinary Anatomy Portfolio Guide, and all **3 Google Forms** with neutral labels because their exact module assignments were not identified.
- **NHMEC 312 — Original Medicine Through the Holistic P.E.N. Way™** now includes the full supplied **12-module pathway**, module reading/assignment instructions, KJV-only app worksheet prompts, module forms where identified, Community Project link, final quiz, and the NHMEC course textbook split into **3 GitHub-friendly PDF parts**.
- **Molybdenum Level 4** now opens with the supplied **Holistic P.E.N. Way™ Neurodevelopmental, Sensory & Regulation Wellness Assessment**, current PENothecary Level 4 page, and the exact supplied Google Form URL.
- **KJV-only rule:** student-facing Scripture in the Version 16 app is KJV. Original Medicine worksheet graphics containing modern-translation wording are not linked as student-facing worksheets; their assignment prompts are reproduced in the app with KJV Scripture.
- Existing Version 15 Family Herbalist and Christian Herbalist content remains intact.
- Existing Version 14 Kitchen PENothecary™ and Molybdenum presentation media remain intact.

## Current placeholders preserved

Version 16 keeps the current-site unfinished classes as **Course in Development** placeholders, including Therapeutic Kitchen (206), Seasonal Wellness (207), Home Herbal Preparations (208), NHMEC A&P 210, Herbal & Pharmaceuticals Interactions, Biblical Foods & Health, Biblical Herbal Healing: From Creation to Christ, Christian Iridology, Make Your Own Herbal Cosmetics, Biblical Anointing Oils in Scripture, NHMEC 301 Holistic Human Anatomy & Physiology, and NHMEC 303 Herbal Pharmacokinetics & Bioavailability. No blank current-site cards were named or numbered.

## GitHub mobile upload

Every new Version 16 file is under the GitHub browser/mobile individual-file limit. Extract the ZIP packages first and upload the individual files to the repository root. Do **not** upload the ZIP files themselves to GitHub.

The large Original Medicine and Overwhelmed Woman resources are intentionally split so they can be uploaded from Android/GitHub web without the previous large-file failure.
